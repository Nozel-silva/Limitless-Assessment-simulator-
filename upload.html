📋 What kind of file can I upload? ▼

Upload any .docx or .txt file containing questions. The AI will figure out the structure automatically — no specific format required. All of these work:

// Numbered with letters 1. What is the capital of Nigeria? A) Lagos B) Abuja C) Kano D) Ibadan Answer: B // Bullet points, no numbers What is 5 + 5? - 8 - 10 - 12 - 15 Ans: 10 // Inline options Which planet is closest to the sun? a. Earth b. Venus c. Mercury d. Mars

  • Options can be on separate lines or on the same line
  • Answer key is optional — include it for scoring, leave it out if not needed
  • "Answer:", "Ans:", "Correct:" — any of these will be recognised
  • The AI handles messy, inconsistent, or mixed formatting in the same file
