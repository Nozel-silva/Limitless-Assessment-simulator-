📋 How to format your Word document ▼

Your .docx file must follow this exact structure for each question:

1. What is 5 + 5? A. 8 B. 10 C. 12 D. 15 Answer: B 2. Which planet is closest to the sun? A. Earth B. Venus C. Mercury D. Mars Answer: C
  • Start each question with a number and a dot — e.g. 1. 2.
  • Options must be A. B. C. D. (capital letter + dot)
  • The answer line must be Answer: X where X is A, B, C, or D
  • Leave a blank line between each question block
  • You can have as many questions as you like
  • The answer line is optional — if omitted, scoring is skipped for that question
